My Programming Experience So Far

August 2026 · ← Back to blog

I want to be honest about my programming background: I am a beginner. Before starting at HZ, I had very little formal coding experience. Most of my time with computers was spent gaming and browsing, not writing code.

What I Had Done Before HZ

  • Basic HTML during PCO preparation (freeCodeCamp — Build a Cat Photo App)
  • Created my first profile.html page as a preparation assignment
  • Installed Git, created a GitHub account, and learned basic commit/push workflow
  • Set up VS Code with Live Server for local development

What I Am Learning Now

During the PCO course I am building this portfolio website using HTML and CSS. I am learning about semantic HTML tags, CSS layout (flexbox, grid), navigation menus, file structure, and how to deploy a site on GitHub Pages.

It is a lot to take in, but I enjoy seeing immediate results — change the code, refresh the browser, and something actually looks different. That feedback loop is what keeps me motivated.

What Comes Next

I know this is just the beginning. Real programming — JavaScript, backend development, databases, security — is still ahead of me. But I am not intimidated. I chose this programme precisely because I want to grow from zero to someone who can actually build useful software.
