My Programming Experience (So Far)

3 September 2026

In the SKC questionnaire I had to describe my programming background. The honest answer: there wasn't much of one. I had opened a code editor a few times out of curiosity, but I never really finished anything.

That changed during the preparation assignment. I went through the freeCodeCamp Responsive Web Design course up to Build a Cat Photo App, and built my first real page: this website's profile page. It was the first time I actually understood what tags like <div> and <section> are for, instead of just copying examples.

What I've learned so far

  • Basic HTML structure: headings, paragraphs, lists, links and images
  • How to style a page with CSS, including colors, spacing and a navigation bar
  • Using Git and GitHub to version and publish my work
  • Hosting a site locally with Live Server and on GitHub Pages

It's a small start, but compared to a month ago I can now actually build and publish a working website, which is more than I expected from myself.
